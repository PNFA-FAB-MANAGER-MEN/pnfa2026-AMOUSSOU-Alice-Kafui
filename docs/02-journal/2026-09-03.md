### 2) Appris

### Nouvelles connaissances

- Python est un langage de programmation permettant d'écrire des instructions exécutées par un ordinateur.
- Découverte de la syntaxe de base de Python.
- Utilisation de print() pour afficher une information.

Exemple :

print("Bonjour, bienvenue en Python !")

Ce programme affiche : Bonjour, bienvenue en Python !

- Utilisation de input() pour demander une information à l'utilisateur.

nom = input("Entrez votre nom : ")
print("Bonjour", nom)

Le programme demande le nom de l'utilisateur, puis l'affiche dans un message de bienvenue.
- Notions sur les variables, les types de variables.

### Nouvelles compétences

- Écrire des instructions simples en Python.
- Afficher du texte à l'aide de "print()".
- Récupérer une information saisie par l'utilisateur avec "input()".
- Utiliser une variable pour stocker une donnée.
- Tester et exécuter un programme simple.

### Ce que je retiens
>«La programmation consiste à donner des instructions précises à l'ordinateur afin qu'il réalise une tâche. Les fonctions "print()" et "input()" constituent des bases importantes pour communiquer avec le programme : print() permet d'afficher une information tandis que input() permet de recevoir une information de l'utilisateur.»
